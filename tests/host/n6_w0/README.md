# N6-W0 private native OPNA ordered-history oracle

Run `python3 tools/test_n6_w0.py --output .local/n6-w0`. The runner compiles the actual `sound/opngenc.c`, `sound/opngeng.c`, `sound/sound.c`, and `sound/opntimer.c` sources in an i286, default-OFF host fixture. It generates its own CMake compile profile under the requested output directory; a pre-existing build tree is unnecessary. The latter two are included through test-only translation-unit seams. No product source or public API is changed. The fixture owns CPU coordinates, one native OPNA voice, Timer A test state, and producer buffer demand; the recorder only observes these controlled operations. The generator is never called by the recorder except for the fixture's requested generation call itself. Its sound-sync wrapper calls the real `sound_sync` exactly once per original invocation.

The proposition tested is narrow: a deterministic initial native renderer plus the identical ordered history, sample frontiers, exact native generation-call partition, and reset epochs reproduces exact signed 32-bit little-endian stereo producer PCM and the qualified renderer fingerprint. It does not claim physical YM2608 timing, arbitrary call-partition invariance, SDL transport behavior, FMGEN, PCM86, ADPCM, Speak Board, or P4 deadline compliance.

## Private schema 1

Each `.bin` file has an 8-byte `N6W0A01\0` magic, little-endian schema number, fixture ID, 44100 Hz, 2 channels, 4 bytes per channel sample, 2457600 Hz base clock, multiplier 20, volume 64, native backend ID 1, board ID `0x04`, CPU mode 0, three configured FM channels, monaural pan flag, initial renderer fingerprint, record count, then fixed-size records. Unknown schema, unexpected profile, trailing bytes, excess record count, inconsistent epochs/frontiers/call IDs, incomplete synchronization, and missing finalization reject replay. These are host fixture capacities (50,000 records, 200,000 frames), not product CSM debt limits.

Every record contains sequence, parent sequence, logical and service-observed time in integer nanoseconds, epoch-local producer sample frontier, generation-call ID, CPU clock coordinate, `soundcfg.lastclock` before/after, kind, epoch, origin, raw register/value, sub-operation index, requested/actual frames, stream remaining before/after, and an auxiliary field. `FRONTIER` explicitly publishes the end of each `GENERATION_CALL`. `FINALIZE` seals a complete ordered prefix through its parent sequence and current frontier. The replay worker never consumes an unfinalized prefix. Generation calls are executed with exactly their recorded frame count; the worker does not choose a quantum or infer one from wall time.

Kinds are `RESET=1`, `REGISTER_ACCEPT=2`, `REGISTER_APPLY=3`, `GUEST_KEY_ACCEPT=4`, `GUEST_KEY_APPLY=5`, `TIMER_A_EXPIRY=6`, `TIMER_STATUS=7`, `PIC_PUBLICATION=8`, `TIMER_REARM=9`, `CSM_PAIR=10`, `DERIVED_KEY_OFF=11`, `DERIVED_KEY_ON=12`, `SYNC_ENTER=13`, `SYNC_EXIT=14`, `GENERATION_CALL=15`, `FRONTIER=16`, `FINALIZE=17`. This fixture fixes chip 0, bank 0, and FM channel 2 in its initialization profile; register/address/value and edge subindex are recorded per operation. Derived CSM key edges retain the CSM pair's parent sequence and subindices 0/1. The pair records first sync, key-off, second sync, key-on in the actual native order. A single producer frontier may hold multiple different ordered operations. This frontier is the existing producer sample boundary, not a physical YM2608 sub-sample coordinate.

The fixture calls `opngen_initialize(44100)`, `opngen_setvol(64)`, `opngen_reset`, `opngen_setcfg(3, OPN_MONORAL)`, then programs a fixed four-operator channel-2 voice and keys it on. The header records profile parameters and the fingerprint of this reconstructed state. The report records source SHA-256 values, source commit, compiler identity, CPU build profile, board/backend, rate, and active source. The final fingerprint is FNV-1a over explicitly serialized little-endian scalar fields of `_OPNGEN`, every channel and slot, including the 32 detune table values reachable from each slot. It excludes pointers, padding, host handles, and opaque raw structs; static generator tables are identified by the source/build metadata. It is a qualification fingerprint, not a save-state format.

Producer PCM is stored in `.s32le`; across a reset the file concatenates epoch outputs, while each record's frontier resets to zero. `report.json` lists every generation call's epoch, ID, epoch-local start frontier, total file start frame, count, origin, byte count, and PCM SHA-256. The runner verifies `bytes = frames × 2 × 4`. It also compares the source history to independently emitted consumed histories and uses both SHA-256 and byte-for-byte PCM/state checks.

Immediate replay applies finalized prefixes serially. Delayed replay first validates the complete plan, copies it into a worker-owned immutable buffer, clears the source-owned record buffer, then applies the same prefixes. The delay is logical execution placement; host scheduler time has no authority over replay. Source recording and each replay are separate processes.

Fixture 13 places two separately ordered CSM pairs at one producer frontier for the N6-W binding qualification. It preserves schema 1 and the 16 existing W0 negative controls; the positive count is now 12.

The quiet-interval pair uses identical semantic operations and sample frontiers but one 9700-frame call versus 9700 one-frame calls. Both recorded plans replay exactly, yet their post-CSM PCM diverges at frame 10000. The active-tone pair changes partition while retaining equal PCM and final fingerprint over its bounded 2740 frames. Negative controls in `report.json` detect omitted/collapsed CSM, key/CSM and frequency-write reorder, ±1 frontier corruption, epoch contamination, premature finalization, retrospective time, 1.5×/1.7× timing stretch, unsupported schema, record capacity, capture overflow, and both directions of partition change. Timing stretch is rejected by exact history/time identity even when PCM is unchanged.
